# Start here

Open this directory as the office application project. Follow [README.md](README.md) for setup, checks, storage bindings, first-administrator authorization and deployment requirements.

The Android source is in `../Field_Officer_App`. Existing APK files are prebuilt artifacts and do not include later source changes until rebuilt and signed.

Read [the current production review](../audit-report/PRODUCTION_HARDENING_2026-10-20.md) and [release gate](../PRODUCTION_RELEASE_GATE.md) before operational use. Older audit screenshots and creation notes describe earlier versions and must not be treated as current verification.
